# SUAIA Game

A computer vision game developed for the SUAIA Tech Subcommittee.

The game uses hand tracking and gesture recognition to control the game using a webcam.

## Requirements

- Python
- uv
- A webcam

## Installation

### 1. Install uv

If you do not already have uv installed, follow the installation instructions here:

https://docs.astral.sh/uv/getting-started/installation/

### 2. Clone the repository and run

```bash
git clone <https://github.com/Lawalabq/SUAIA_game.git
cd SUAIA_game
uv run python -m suaia_game
